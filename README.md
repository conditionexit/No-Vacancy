# No-Vacancy

A 2D maze-escape game developed in Java using libGDX.

## About the Project

No-Vacancy is a university project developed for
the Programming Fundamentals course at AZSET.

Players explore mysterious mazes, collect keys,
avoid enemies and traps, and attempt to escape.
